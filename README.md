# LLMeter

各 LLM サービス（Claude / Codex / GitHub Copilot / Gemini）の利用状況クォータをひと目で確認できる、ブラウザ完結型のダッシュボードです。ビルドツールやバックエンドを持たない静的サイトで、入力したデータは端末の `localStorage` にのみ保存されます。

## 機能仕様

### ダッシュボード（`#dashboard`）

- **サマリー**: 4サービスの平均残量、残量が最も少ないサービス、接続中のサービス数を表示します。
- **クォータ一覧**: サービスごとにカード表示します。各カードには以下を含みます。
  - サービス名・提供元（vendor）・接続状態
  - 利用区分（例: Weekly messages / 5-hour limit / Daily requests / Premium requests）と残量パーセンテージ
  - 残量バー（プログレスバー、サービスごとの色分け）
  - 残量数値 / 上限数値、リセットタイミング
  - 現在のモデル・プラン名
  - カード上の「Edit」ボタンから該当サービスの設定を直接開ける
- **インサイト**: 残量が最も少ないサービスの残量が20%未満の場合に注意喚起メッセージを表示し、そうでなければ「余裕あり」のメッセージを表示します。過去7日間の利用状況を示すダミーの週次バーグラフも表示します（静的データ）。
- **テーマ切り替え**: ライト/ダークモードをトグルボタンで切り替え可能。選択状態は `localStorage`（`llmeter-theme`）に保存され、次回訪問時も維持されます。
- **Refresh ボタン**: クリックすると更新中の演出（ローディングアニメーション、トースト通知）を表示します。実際の外部データ取得は行いません（デモ的な挙動）。

### クォータ編集（設定ダイアログ）

- ヘッダーの「クォータを編集」またはカードの「Edit」から開けます。
- サービスごとに以下を編集できます。
  - 残り（remaining）
  - 上限（limit）
  - モデル / プラン名（最大80文字）
- バリデーション: 残量は上限以下である必要があり、違反時はエラーメッセージを表示して保存をブロックします。
- 保存すると `localStorage`（`llmeter-quotas-v1`）に反映され、ダッシュボードが即時に再描画されます。
- 「デモデータに戻す」ボタンで、保存済みのカスタム値を破棄し初期のデモデータに戻せます。

### 対象サービス（デモデータ）

| サービス | 提供元 | 利用区分 | 初期値（残量/上限） |
|---|---|---|---|
| Claude | Anthropic | Weekly messages | 1248 / 1600 |
| Codex | OpenAI | 5-hour limit | 84 / 200 |
| GitHub Copilot | GitHub | Premium requests | 273 / 300 |
| Gemini | Google | Daily requests | 975 / 1500 |

### データ保存・プライバシー

- すべてのデータはブラウザの `localStorage` にのみ保存され、外部サーバーへの送信は行いません（フッターに明記）。
- 保存データが破損・不正な場合は該当フィールドごとにデフォルト値へフォールバックします。

## 技術構成

- 静的3ファイル構成: `index.html` / `app.js` / `styles.css`（フレームワーク・バンドラー不使用）
- 日本語UI（`lang="ja"`）

## 開発

```bash
npm start   # python3 -m http.server 4173 でローカル起動
npm run check  # node --check app.js で構文チェック
```

詳細な実装ガイドは [`CLAUDE.md`](./CLAUDE.md) を参照してください。
